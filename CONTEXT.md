# Portfolio

Mico Rintala's personal portfolio site: presents who Mico is, the work Mico has built, and the skills that work demonstrates. Finnish is the primary language, English secondary.

## Language

**Project**:
A curated portfolio entry representing one piece of work, regardless of how many repos it spans.
_Avoid_: Repo, app, case study

**Featured**:
A Project shown on the home page. Every Project, Featured or not, has its own page and appears in the full project list.
_Avoid_: Pinned, highlighted, archived (for the non-Featured ones)

**Group**:
A named cluster of related Projects with a short introduction of its own (e.g. Tectonic). Optional: most Projects belong to no Group.
_Avoid_: Ecosystem, umbrella, category, tag

**Write-up**:
The hand-written prose describing a Project, authored separately in each supported language. It may be as short as one sentence; a small Project needs no more.
_Avoid_: Description (that belongs to the Repository), content, post

**Role**:
Mico's part in a Project (e.g. sole author, lead in a team of four, contributor), stated on every Project.
_Avoid_: Position, title, credit

**Repository**:
A GitHub repository whose live metadata (languages, last push) is shown on the Project it belongs to. A Project links to zero or more Repositories, which need not be owned by Mico; a Repository that no Project links to is not shown.
_Avoid_: Repo (in prose), source

**Skill**:
A technology or practice Mico claims, backed by evidence: the Projects that declare it, Featured or not. A Skill no Project declares does not appear; a Repository alone is never evidence.
_Avoid_: Tech, stack item, competency
