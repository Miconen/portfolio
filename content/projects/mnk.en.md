A real-time chat app built as a school team project: multiple chat rooms and hand-built JWT authentication. I was in charge of the backend, its integration with the frontend, and organising the project.

- .NET/C# backend with SignalR, EF Core and PostgreSQL
- Angular frontend in TypeScript
- Docker and automated tests on Azure
