A tool that parses Counter-Strike 2 demo files and looks for bad habits. Instead of raw statistics, it tells you what to fix.

- Go engine: demo parsing, analyzers, a REST API and SQLite
- SvelteKit dashboard for reviewing results
- Analyzers for premature firing, spray accuracy, shooting while moving and the lifecycle of each duel, among others
- Built with help from GPT
