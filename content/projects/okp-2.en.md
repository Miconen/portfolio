A school team project that shows places, activities and events from the MyHelsinki Open API based on the user's location or a search. Weather comes from OpenWeatherMap and maps from Google Maps. Registered users can save favourites.

- ASP.NET/C# backend with EF Core and PostgreSQL
- Angular frontend
- Docker
