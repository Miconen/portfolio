Tooling for the clan's competitions and events.

- **Bingo bot (2024)**: a Python Discord bot for a ten-day bingo event with 75 participants. It rendered each team's progress with Pillow, and I improved it mid-event based on feedback.
- **Bingo site (2026)**: a TypeScript monorepo I develop with another developer. Playwright and Vitest tests, OpenTofu infrastructure, and Wise Old Man and RuneProfile integrations. Built with help from Claude.
- **Player scoring**: the wom-player-score script grew into player-performance-ranker, which ranks players by participation, dedication and achievements. Built with help from GPT.
